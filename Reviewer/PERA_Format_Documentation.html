📊 System Overview

MyFits is an end-to-end digital wardrobe management system expertly designed to help users track their clothing inventory, seamlessly generate visual outfits, schedule daily looks via a calendar, and autonomously sync laundry chore cycles to restrict unwearable bounds. The system provides real-time drag-and-drop styling insights and supports robust server-side data isolation.

Technology Stack:

  • Backend: PHP via PDO
  • Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)
  • Database: MySQL
  • Framework: Bootstrap 5 for responsive gridding
  • Font: Google Poppins font family

The MySQL database maintains absolute relational referential integrity across 4 main tables handling nested mapping parameters:

1. users Table

Purpose: Tracks active authentication logic and structural user identity metrics.

Purpose: Retains absolute inventory arrays directly associating visual assets to a specific user context.

3. outfits Table

4. schedule Table

Purpose: Manages exact chronologically-bound mappings routing outfits towards specific user dates contextually.

  • schedule_id (INT, PRIMARY KEY)
