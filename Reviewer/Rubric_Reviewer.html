4. Database Integration

Requirement: Database connection is stable; all CRUD operations work correctly with accurate queries.

How MyFits Achieves Excellence:

Absolute Stability & Complex Queries: The MySQL connection utilizes PHP Data Objects (PDO) set strictly to catch fatal exceptions.

includes/db_connect.php backend/get_outfits.php
// 1. Stable, Exception-Managed PDO Database Connection $pdo = new PDO("mysql:host=localhost;dbname=myfits", "root", ""); $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
How we use this: `PDO::ERRMODE_EXCEPTION` guarantees that if the SQL server goes offline, it securely throws a programmatic error rather than leaking raw backend passwords or PHP logic text out onto the public screen safely.
// 2. Advanced Multi-table Queries mitigating the N+1 database problem $query = "SELECT outfits.id, c1.image_path as top_img, c2.image_path as bot_img FROM outfits INNER JOIN clothes c1 ON outfits.top_id = c1.id INNER JOIN clothes c2 ON outfits.bottom_id = c2.id";
How we use this: In the catalogue view, relying on basic `SELECT *` loops would crash the server (running a new DB query for every single item inside an outfit). Instead, we wrote highly advanced relational `INNER JOIN` logic forcing MySQL's engine to merge all 4 tables dynamically simultaneously, solving performance bottlenecks efficiently!
